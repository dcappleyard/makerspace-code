# python-projects

Standalone `python3` scripts — no monorepo-wide package manager or virtualenv convention. Each subproject that imports third-party packages has its own lightweight, unpinned `requirements.txt` (just package names, no version pins) — follow that pattern for new subprojects rather than introducing poetry/uv/pipenv.

## Subprojects

- **`grayscale_image_conversion/`** — `prepare_image.py`, a CLI that fits a ~6:17 panorama photo onto the EE03 panel canvas (EXIF orientation, percentile contrast mapping, Floyd-Steinberg dithering to 4-bit grayscale), nibble-packs it to a display-ready `.bin`, and interactively prompts for metadata to write a matching `.xml` sidecar (+ a `.png` preview) for the `esp32-projects/panorama_photo_frame_w_counter/` SD-card frame. Deps: `Pillow`, `numpy`.
- **`usgs_monitoring/`** — `usgs_trend_summary.py` and `yahara_usgs_latest.py`, CLI tools that hit the USGS water-data API (`waterservices.usgs.gov`) for Yahara river monitoring sites near Madison, WI. Deps: `requests`. Overlaps with `../tidbyt-starlark/usgs_tracker`, `yahara_candle`, and `yahara_plot`, which target the same sites/parameters as the Tidbyt display layer — check both sides when changing site IDs or parameter codes.
- **`subtitle_player/`** — `subtitle_player.py`, a pygame app that plays an `.srt` on a black full-screen window so a DVD can run on a DVD player while the subtitles are read off a computer. Shows a rolling ±N-second context window of cues (current line white, neighbours dimmed, current line anchored at a fixed height), with scrub/nudge keys and an `S` "snap nearest cue to now" key for aligning against the disc. Deps: `pygame`. **Needs `/usr/bin/python3`** (3.9) for its venv — the `python3` on `PATH` is PlatformIO's and has no working GUI stack; see the subproject README.
- **`eink_photo_server/`**: a FastAPI service, run in Docker on a Raspberry Pi, that feeds the e-ink photo frames over a **pull** model.
  - **Structure:** each device in `devices.yaml` pairs a *protocol adapter* (`server/protocols/`, e.g. Bloomin8 `/eink_pull`) with an image *pipeline* (`server/pipelines/`, auto-registered via `@register`).
  - **Shared:** playlists with time windows, scheduling (`schedule.py`), and the prepared-image cache (`prepare.py`). The cache is keyed by source/pipeline version/geometry/tuning/focal point.
  - **UI:** Jinja pages (`server/web/`), including a Test card tab. `testcards.py` renders 3-column A/B/C tuning cards, which are saved with neutral per-photo tuning. A one-shot "show next" override is stored in `device_state.queued_photo_id`.
  - **Data:** runtime data, including `devices.yaml` with its tokens, lives in the git-ignored `data/`.
  - **Extending:** new frame types (e.g. the planned ESP32 frame: pre-dithered, 4bpp-packed) = new protocol module + new pipeline module. The core doesn't change.
  - **Deps:** `fastapi`, `uvicorn`, `Pillow`, `jinja2`, `python-multipart`, `PyYAML`. No test suite. Verify with the curl/TestClient flows in its README. Add new columns to existing tables via `db.MIGRATIONS`, because the Pi already has a live database.
- **`internet_connection_logging/`** — `check_netlog.sh`, a **bash/awk** script (not Python, despite the parent folder) that analyzes `network_health_log.csv`. The process that generates that CSV lives outside this repo (e.g. a cron/launchd job), so this directory only contains the analysis side.
